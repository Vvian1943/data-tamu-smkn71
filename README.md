# Aplikasi Data Tamu SMKN 71 Jakarta

Aplikasi untuk mengelola data siswa dan guru.

## Fitur
- Tambah/edit/hapus data siswa
- Tambah/edit/hapus data guru
- Cari data
- Cetak laporan
- Dark mode

## Cara Install
1. Download atau clone repo ini
2. Import database dari folder `db`
3. Jalankan di XAMPP
