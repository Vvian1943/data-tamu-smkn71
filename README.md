# 📚 Aplikasi Data Tamu SMKN 71 Jakarta

Aplikasi web sederhana untuk mengelola data siswa dan guru dengan tampilan **pastel modern** dan **dark mode**.

---

## ✨ Fitur Utama

| Fitur | Keterangan |
|-------|-------------|
| 📝 **Data Siswa** | Tambah, edit, hapus, cari, dan cetak data siswa |
| 👨‍🏫 **Data Guru** | Tambah, edit, hapus, cari, dan cetak data guru |
| 🌓 **Dark Mode** | Tampilan siang/malam dengan penyimpanan preferensi |
| 🔍 **Pencarian** | Cari data siswa/guru dengan cepat |
| 🖨️ **Cetak Laporan** | Cetak data ke printer atau PDF |
| 📱 **Responsive** | Tampil bagus di desktop, tablet, dan HP |

---

## 🛠️ Teknologi

- **PHP** - Backend & koneksi database
- **MySQL** - Penyimpanan data
- **HTML5 & CSS3** - Struktur & styling pastel
- **JavaScript** - Dark mode toggle
- **Font Awesome 6** - Ikon-ikon keren

---

## 🚀 Cara Install

### Prasyarat
- XAMPP / WAMP / LAMP
- PHP 7.4+
- MySQL 5.7+

### Langkah-langkah

```bash
# 1. Clone repository
git clone https://github.com/Vvian1943/data-tamu-smkn71.git

# 2. Pindah ke folder proyek
cd data-tamu-smkn71

# 3. Pindahkan ke htdocs (XAMPP)
# Copy folder ke C:\xampp\htdocs\

# 4. Import database
# Buka phpMyAdmin -> Buat database baru -> Import file dari folder /db

# 5. Jalankan aplikasi
# Buka browser -> http://localhost/data-tamu-smkn71
