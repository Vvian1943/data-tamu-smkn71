# Aplikasi Data Tamu SMKN 71 Jakarta

Aplikasi untuk mengelola data Tamu siswa dan guru di SMKN 71 Jakarta.

## Fitur
- Tambah/edit/hapus data siswa
- Tambah/edit/hapus data guru
- Cari data
- Cetak laporan
- Dark mode
